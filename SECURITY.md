# Security Policy

## Поддерживаемые версии

Актуальная ветка `main` — единственная, для которой принимаются security-фиксы.

## Как сообщить об уязвимости

**Не создавай публичный GitHub Issue** с деталями эксплойта или утечками секретов.

Предпочтительно:

1. [GitHub Security Advisories](https://github.com/hopelessness-7/kopeika-front/security/advisories/new) для этого репозитория, или
2. Email: [hopelessness1808@gmail.com](mailto:hopelessness1808@gmail.com) с темой `[kopeika-front security]`.

Опиши затронутый экран или компонент, шаги воспроизведения и влияние. Ответим по возможности быстро; после фикса можем попросить проверить патч.

## Что не считается уязвимостью этого репо

- Публичный `VITE_VAPID_PUBLIC_KEY` в клиентском бандле (так устроен Web Push; приватный ключ только на бэке).
- Локальный `VITE_USE_MOCKS=true` и dev-сервер на `0.0.0.0` — ожидаемо для разработки.
- Отсутствие prod hardening (HTTPS, CSP на хостинге) — это зона деплоя, не этого репозитория.
